ContraForce is the Agentic Security Delivery Platform for Microsoft security teams, MSPs, MSSPs, and security operations teams. It provides AI‑powered triage, investigation, response, tuning, ticketing, and reporting on Microsoft Defender XDR and Sentinel. The platform offers a free 30‑day trial with no credit card required, enabling service providers to scale SOC delivery without hiring additional analysts.

**Areas:** Security · Software-as-a-Service · Cybersecurity · Microsoft · MSP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Contraforce: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
